# XTools 蓝图节点速查表

> **版本**: 1.0 | **引擎**: UE 5.3-5.6 | **作者**: XIYBHK

---

## XTools - 核心工具库

### 资产工具
- **复制并烘焙BaseColor到顶点色** - 内容浏览器静态网格体右键菜单，默认复制资产后将材质 BaseColor 按 UV 烘焙并写入副本资产顶点色，便于后续体素点位优先读取颜色
- **烘焙材质颜色到资产顶点色** - 蓝图函数，将静态网格体材质 BaseColor 按 UV 烘焙并写入指定 LOD 的资产顶点色
- **导出蓝图逻辑流** - 内容浏览器蓝图右键菜单，将选中蓝图图表、节点、引脚和连接导出为 JSON 与 Markdown

### Actor 工具
- **获取附加的Actor最高级** - 从组件向上查找最顶层的匹配父Actor

### 贝塞尔曲线
- **计算贝塞尔曲线点** - 计算任意阶贝塞尔曲线上的点位置，支持匀速模式

### 几何采样
- **在模型中生成点阵** - 在模型内部生成均匀分布的点阵
- **清理点阵生成缓存** - 清理采样计算缓存

### 测试工具
- **测试PRD分布** - 测试伪随机分布算法

### 蓝图清理
- **预览清理World Context参数** - 扫描需要清理的参数
- **执行清理World Context参数** - 清理未连接的World Context参数

## FieldSystemExtensions - 场系统扩展

### 筛选器创建
- **创建基础筛选器** - 创建基础MetaDataFilter
- **创建排除角色筛选器** - 创建排除角色的筛选器
- **创建破碎专用筛选器** - 创建只影响破碎物体的筛选器
- **获取或创建Actor筛选器** - 获取或创建筛选器缓存

## PointSampling - 点采样系统

### 2D采样
- **泊松圆盘采样2D** - 在2D平面生成均匀分布的点

### 3D采样
- **泊松圆盘采样3D** - 在3D空间生成均匀分布的点

### 网格采样
- **网格表面泊松采样** - 在静态网格表面生成均匀分布的点（仅编辑器）
- **从静态网格体生成点阵** - 从静态网格体顶点/三角面生成点位，支持LOD、边界顶点和去重
- **从静态网格体生成体素点位** - 将静态网格体转换为规则体素点位，支持仅表面/内部填充，返回位置、变换、颜色、材质索引和表面标记；颜色优先来自CPU可读资产顶点色插值，其次尝试UV采样可读材质贴图或编辑器BaseColor链简单颜色常量；运行时需要StaticMesh启用Allow CPU Access，MaxVoxelCount达到上限时会截断或提前停止扫描

## AxisLocker - 物理轴向锁定

### 轴向锁定
- **轴向锁定组件** - 可挂载到Actor，按预设或手动6轴开关在开始游戏或运行时应用物理自由度锁定
- **锁定轴向** - 对物理组件按位移/旋转6轴组合锁定自由度
- **解除全部锁定** - 解除目标物理组件的全部轴向锁定
- **获取锁定状态** - 读取目标物理组件当前自由度和轴锁定状态
- **是否有轴被锁定** - 查询目标物理组件是否存在任意轴锁定
- **预设转锁定状态** - 将轴向锁定预设转换为锁定状态结构
- **应用锁定预设** - 对目标物理组件一键应用站立不倒、只绕Z轴、水平移动或完全冻结等预设

## BlueprintExtensions - 蓝图扩展

### 流程控制
- **带延迟的WhileLoop** - 事件图 Latent 循环节点，支持循环体延迟与 Break 中断

### Map扩展
- **Map获取Key** - 通过索引获取Map的Key
- **Map添加MapItem** - 向嵌套Map添加项
- **Map移除MapItem** - 从嵌套Map移除项

### Set扩展
- **Set转数组** - 将Set转换为Array
- **Set并集** - 计算两个Set的并集
- **Set交集** - 计算两个Set的交集
- **Set差集** - 计算两个Set的差集

### Array扩展
- **数组去重** - 移除数组中的重复元素
- **数组分块** - 将数组分割成多个子数组
- **数组随机元素** - 获取数组中的随机元素

### 进程管理
- **通过名称调用函数** - 动态调用对象的函数
- **通过名称调用事件** - 动态触发蓝图事件

### Mesh反馈
- **收集Actor网格体组件** - 按网格体类型和组件Tag从Actor收集 Mesh 组件
- **为网格体创建动态材质实例** - 为网格体组件逐材质槽创建或复用动态材质实例
- **为Actor网格体创建动态材质实例** - 先收集Actor网格体组件，再批量创建或复用动态材质实例

### 子弹追踪
- **更新追踪弹运动** - 支持纯追踪、预测拦截和比例导引，可写入 ProjectileMovement 并更新旋转
- **重置追踪弹状态** - 重置追踪弹运动节点使用的运行时状态

### 样条线移动
- **重置样条跟随状态** - 清空样条跟随距离和方向缓存
- **计算样条初始右偏移** - 计算Actor相对样条中心线的初始右侧偏移
- **计算样条跟随目标** - 输出样条前视目标、移动方向和速度倍率，不主动移动
- **沿样条线添加移动输入** - 计算样条前视目标并对Pawn调用 AddMovementInput
- **获取样条AI移动目标** - 输出可接入 AI MoveTo 的样条目的地
- **应用样条跟随速度到角色移动** - 将样条跟随速度倍率写入 CharacterMovement
- **恢复样条跟随角色移动** - 恢复样条跟随自动修改过的角色移动参数
