# XTools 函数封装候选：语料 × 插件函数库 去重核验

**目的**：从 114 包全量语料中挖出"通用、有复用价值、且插件当前未提供"的蓝图节点，作为封装候选清单。
**前提**：按老大定调 —— **不考虑签名前后兼容，仅做通用节点新增**，不涉及旧蓝图原地替换。
**方法**：离线读取（不启动 UE）。

| 侧 | 数据源 | 规模 |
|---|---|---|
| 插件侧 | `Source/**/*.h` 的 `UFUNCTION(BlueprintCallable/BlueprintPure)` | **35 库 / 327 蓝图函数**（Runtime 28 + Editor 7） |
| 语料侧 | `01_Manifest.json` 的 `graphs[].name`（`parent=…BlueprintFunctionLibrary`） | **13 函数库 / 236 函数** |
| 补充 | 自定义 K2Node（`BlueprintExtensions/Public/K2Nodes/`） | 13 个，**均为流程控制类** |

**判定规则**：语义等价即"已覆盖"；仅当插件**无任何对应形态**（函数库 / K2Node / 组件类公开接口）时判为"缺口"，缺口均给出 grep 证据。

## 1. 已覆盖 / 不建议封装（无需重复建设）

约 **70/236** 与插件现有能力语义重叠，其余属项目定制或数据层：

| 类别 | 语料例子 | 对应 / 理由 |
|---|---|---|
| 排序 / 截取 / 反转 / 去重 | SimpleLib（~44 函数） | `USortLibrary` 35 函数（`SortActorsBy*` / `SortVectorsBy*` / `Slice*ArrayBy*` / `Reverse*Array` / `RemoveDuplicate*` / `SortArrayByPropertyInPlace`） |
| 阵型与点位生成 | 矩形/圆/球/螺旋/样条/线条/盒体/平面 | `UFormationSamplingLibrary` 31 + `UPointSamplingLibrary` 14 |
| 加权随机 / 严格权重 / 采样 / 打乱 / PRD / 流送采样 | RandomLib、BFL_04（~6 函数） | `URandomShuffleArrayLibrary` 16（`Array_RandomSample` / `Array_StrictWeightRandomSample` / `PseudoRandomBool*` / `*FromStream`） |
| 贝塞尔点、最高父级 Actor、所有附加子 Actor、网格内点阵采样 | AdvancedLib | `UXToolsLibrary`（`CalculateBezierPoint` / `GetTopmostAttachedActor` / `GetAllAttachedActorsRecursively` / `SamplePointsInsideMesh*`） |
| 取消锁轴 | BFL_08 | `UAxisLockLibrary:UnlockAll` |
| 网格体动态材质实例、收集网格体组件 | BFL_08 | `UMeshFeedbackLibrary` |
| 线条 / 球体 Trace（通道 / 对象） | BFL_10 | `UTraceExtensionsLibrary` |
| 库内私有实现 | `快速排序浮点_私有`、`冒泡排序整数_私有` | `_私有` 是作者命名习惯（非访问级别）；UE 已有 `Array_Sort`，无需重复 |
| 项目定制逻辑 | `F_设置播放时长`（依赖具体时间轴资产）等 `F_` 前缀函数 | 通用性不足，留在项目层 |
| 数据资产 | `BP_背包资源Base` 的 `PrimaryDataAsset` | 数据应留编辑器 |

## 2. 推荐封装清单（未覆盖 + 通用）

> **P0** 高频基础 / **P1** 常用 / **P2** 锦上添花。语料函数名沿用原中文名；括号内为建议 C++ 命名。

**族 1 ｜范围随机 ★ P0 —— 最大单一缺口**
> 证据：`URandomShuffleArrayLibrary` 只做"采样/打乱/PRD"；grep `RandomFloatInRange|RandomUnitVector|RandomRotator|RandomColor` **零蓝图命中**（仅测试库与编辑器 UI 内部在用）。

| 语料函数 | 建议命名 |
|---|---|
| 范围内随机向量 / 流送中 | `RandomVectorInRange` / `…FromStream` |
| 范围内随机浮点 2D / 流送中 | `RandomFloat2DInRange` |
| 范围内随机旋转 / 流送中 | `RandomRotatorInRange` |
| 随机线性颜色 / 流送中 | `RandomLinearColorInRange` |
| 范围内随机线性冲量 / 流送中；复合冲量 | `RandomLinearImpulseInRange` / `RandomImpulseInRange` |
| 生成随机浮点 / 整数 / 向量数组 | `MakeRandomFloatArray` / `…IntArray` / `…VectorArray` |
| 浮点 / 整数输出正负值 | `RandomSignFloat` / `RandomSignInt` |
| 0~浮点输出随机值 | `RandomFloat01` |
| 浮点 / 向量正负输出随机值；0-向量正值 | `RandomSignedFloat` / `RandomSignedVector` / `RandomPositiveVector` |
| 扰乱坐标（0-偏移 或 输出正负值） | `JitterVector` |
| 固定随机流送 / 随机流送 / 坐标流送 | `MakeRandomStream` / `…FromSeed` / `…FromLocation` |
| 从浮点/整数/Actor/向量数组获取随机子数组 | `RandomSubArray`（与 `Array_UnweightedRandomSample` 是否等价存疑） |

> 插件已有完整 `*FromStream` 设计范式，这套"范围随机"可直接配套流送版，与既有 PRD 体系互补。

**族 2 ｜向量 / 旋转体工具 ★ P0**
> 证据：`UTransformExtensionsLibrary` 仅 5 函数（`TLocation` / `TRotation` / `AxisForward` / `AxisRight` / `AxisUp`），**无向量运算辅助**；旋转体运算无任何节点。

| 语料函数 | 建议命名 |
|---|---|
| 去除Z轴 / 去Z且规格化 | `FlattenZ` / `NormalizeFlattenZ` |
| 向量合并XYZ | `MakeVectorFromScalars` |
| 向量输出Z / 去除Z | `GetZ` / `SetZeroZ` |
| 最近位置 / 最远位置 | `NearestPoint` / `FarthestPoint` |
| 两点之间的某位置 | `PointBetween` |
| 判断位置是否在某方向上 | `IsPointInDirection` |
| 翻转 2D 向量 | `Flip2D` |
| 向量夹角度数 | `AngleBetweenDegrees` |
| 向量数组 中间/平均位置、加向量、乘浮点、乘向量 | `VectorArrayMidpoint` / `AverageVector` / `AddVectorToArray` / `ScaleVectorArray` / `MultiplyVectorArray` |
| 旋转体只输出Z | `GetYawOnly` |
| 旋转体附加 / 相加 / 相减 | `CombineRotators` / `AddRotators` / `SubtractRotators` |

## 3. 结论

| 问题 | 结论 |
|---|---|
| **最大缺口** | **范围随机族**（~24 函数）—— 随机库只做"采样/打乱/PRD"，缺基础"取值范围随机"，且缺 `Vector/Rotator/LinearColor/Impulse` 类型 |
| **第二缺口** | **向量/旋转体**（16）、**方向与冲量**（12）、**网格体属性设置**（7）—— 纯工具、零资产依赖、通用性强 |
| **部分缺口** | 数组工具（类型转换 / 筛选提取）、Trace（胶囊体 / 批量） |
| **完全重叠** | 排序、阵型点位、加权随机、贝塞尔、父级附加 —— 约占语料 **70/236**，无需重复 |
| **落地顺序** | P0 范围随机 + 向量/旋转体 → P1 冲量 + 网格体属性 + 变换/碰撞 + 朝向 → P2 数组补充 + Trace + 杂项 |

## 4. 边界与误读防护

- **判定为静态源码 grep**：依据 `Source/**` 下无对应蓝图暴露点；未做编译期符号表核验，宏生成 / 反射动态注册的函数可能漏判。
- **语义去重为主观判断**：如"随机子数组"与 `Array_UnweightedRandomSample` 是否等价，取决于是否要求保持原顺序 —— 已标注存疑。
- **热度未计入本表**：仅做定性核验；调用频次排序见 `蓝图语料_设计亮点与C++改造候选_2026-09-15.md`。
- **未做**：未编译、未启动 UE、未实测性能。
