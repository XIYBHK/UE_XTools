# XTools 提交前检查清单

本清单面向代码提交和发布前自查。它只保留当前可执行的检查，不记录历史修复次数或单次事故。

## 1. 变更范围

- [ ] 每个修改行都能追溯到当前任务。
- [ ] 未格式化或重构无关文件。
- [ ] 本次改动产生的无用 include、变量和函数已清理。
- [ ] 用户已有工作树修改未被覆盖或回滚。
- [ ] `git diff --check` 通过。

## 2. 模块与目标

- [ ] Runtime 模块未依赖 Editor/UncookedOnly 模块。
- [ ] K2Node 和资产编辑器代码位于 Editor/UncookedOnly 模块。
- [ ] 公共头暴露的外部类型有正确 Public 依赖。
- [ ] `.cpp` 私有使用的模块优先放入 Private 依赖。
- [ ] Editor Target 和 Game Target 都验证过受影响模块。
- [ ] Shipping 目标不会编译进测试注册或 Editor API。

快速扫描：

```powershell
rg -n "UnrealEd|BlueprintGraph|KismetCompiler|EditorSubsystem" Source\<RuntimeModule>
rg -n "K2Node" Source\<RuntimeModule>\Public Source\<RuntimeModule>\Private
```

扫描命中需要人工判断，不等于自动判错。

## 3. IWYU 与反射

- [ ] 每个文件显式包含使用的类型。
- [ ] `*.generated.h` 是头文件最后一个 include。
- [ ] 没有依赖 PCH 或其他头的传递包含。
- [ ] 新增/修改 `UCLASS`、`USTRUCT`、`UENUM`、`UFUNCTION` 已强制 UHT。
- [ ] Blueprint 参数和返回类型受 UHT 支持。
- [ ] UE 5.4-5.8 StrictIncludes 构建可通过。

## 4. K2Node

- [ ] 引脚连接通过 Schema helper，并检查返回值。
- [ ] 重建节点后重新查找 Pin，没有复用旧指针。
- [ ] 展开后按父类契约断开原节点连接。
- [ ] 通配符类型在连接、断开和重建时都正确传播。
- [ ] 运行时逻辑位于 Runtime 模块，不复制到节点展开代码。
- [ ] CustomThunk/K2Node 使用真实 Blueprint 图编译和执行测试。

## 5. 生命周期与异步

- [ ] 跨帧回调没有捕获裸 UObject/Actor 指针。
- [ ] 弱引用在回调执行时重新校验。
- [ ] Timer、Ticker、委托、异步句柄和 Slate 窗口有清理路径。
- [ ] Owner/World 销毁后动作停止或安全跳过。
- [ ] 没有 Slate 内容控件与窗口之间的强引用环。
- [ ] 锁内不执行 Blueprint 或可能重入的外部回调。

## 6. 并发

- [ ] 共享状态的完整读-算-写序列处于同一锁或原子事务。
- [ ] 多把锁有固定获取顺序。
- [ ] 容器锁没有被误解为允许后台线程操作 UObject/Actor。
- [ ] 并发测试使用确定性输入并断言最终不变量。

## 7. 数值、排序与缓存

- [ ] 浮点比较器定义 `NaN`、`±Inf`、`±0` 和相等值语义。
- [ ] 排序比较器满足严格弱序。
- [ ] 随机测试使用固定种子或注入源。
- [ ] 缓存键覆盖所有影响结果的输入。
- [ ] 缓存有明确失效、生命周期、线程安全和内存上界。
- [ ] 性能结论来自可复现测量，不是估算百分比。

## 8. API 与兼容

- [ ] 公共 API 的空值、失败和回退契约写入 ToolTip/文档。
- [ ] 删除反射类型前扫描 C++、Blueprint 测试资产和序列化引用。
- [ ] 跨版本差异使用 `XToolsVersionCompat.h`。
- [ ] 条件编译只覆盖真实 API 差异。
- [ ] 最低和最高支持 UE 版本都验证过。

## 9. 自动化测试

- [ ] 新测试会复现原始缺陷或钉定新增行为。
- [ ] 测试名称位于稳定的 `<Product>.<Module>.<Feature>` 层级。
- [ ] 异步测试等待状态条件，不使用固定长睡眠。
- [ ] World、地图、Slate 和资产 fixture 能独立清理。
- [ ] 报告中实际执行数等于预期数。
- [ ] `failed == 0`、`notRun == 0`、`inProcess == 0`。
- [ ] Warning 有明确策略，不把未知 Warning 永久豁免。

## 10. 文档与发布

- [ ] `UNRELEASED.md` 记录用户可见变更。
- [ ] README、AGENTS 和模块文档与当前代码一致。
- [ ] 文档没有个人盘符、已删除 API、相对时间或伪性能数据。
- [ ] Markdown 相对链接存在。
- [ ] 版本号在 `XTools.uplugin`、版本宏和发布记录中一致。
- [ ] 发布前 UE 5.3-5.8 BuildPlugin 矩阵通过。
